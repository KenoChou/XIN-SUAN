# 薪算 · XIN-SUAN

微信原生小程序薪资计算工具，纯前端 MVP。

## 当前功能
- 月薪到手估算：可调整税前工资、城市、公积金比例、社保缴费基数及个人缴费比例
- 结果明细：个人社保、公积金、个税估算、预计月到手与年到手
- Offer 对比：月薪、薪资月数、奖金与公积金比例对比
- 本地记录：主动保存计算结果、查看历史、清空记录
- 职场工具入口：年终奖、离职补偿、加班费入口及说明
- 本地计算，无需业务后端

## 本地运行
1. 安装并打开微信开发者工具。
2. 选择「导入项目」，选择本仓库目录。
3. 当前 project.config.json 使用 touristappid 作为占位值；正式开发/发布时换成自己的小程序 AppID。
4. 预览工资计算、结果页、Offer 对比和本地记录。

## 计算口径与发布前事项
- 当前城市字段用于界面展示；社保、公积金默认比例为演示值，不是城市官方政策配置。
- 个税采用年度综合所得简化估算：减除费用按每年 60,000 元，使用综合所得年度税率表，不覆盖所有专项附加扣除、特殊收入及其他税务情形。
- Offer 对比将奖金并入简化年度收入估算，不等同于奖金单独计税或正式个税申报。
- 正式发布前，需核对目标城市当年度社保/公积金缴费上下限、个人比例、税务规则与隐私合规要求，并对计算结果进行测试。
- 所有计算在客户端完成，记录默认保存在本地；卸载或清理本地数据可能导致记录丢失。
- 本工具结果仅供个人规划参考，不构成税务、法律或劳动争议处理意见。
